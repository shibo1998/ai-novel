## 0. 范围

### 0.1 本批做

| 编号 | 能力 | 对应上游项 |
|---|---|---|
| 13-01 | `settings.providers` 支持多个接口，每个含 `base_url` / `api_key` / `label` | 「不同的 url、key」 |
| 13-02 | 模型值支持 `端点名@模型名` 前缀语法；无前缀 = 默认接口（名为 `openai`，兼容旧数据） | 同上 |
| 13-03 | `models.resolve()` 返回 `provider`，`pipeline._call` 按端点选客户端 | 同上 |
| 13-04 | 价格按 `端点@模型` 优先、裸模型名兜底 | 不同中转站同价不同名 |
| 13-05 | 设置页可增删改多个接口 | 同上 |
| 13-06 | 档位选择器升级为「接口 + 模型」两段下拉，存成 `端点@模型` | 同上 |
| 13-07 | `GET /api/models?provider=` 按端点列模型 | 同上 |
| 13-08 | `generation_log.provider` 记录真实端点名（原为常量 `openai`） | 可追溯 |

### 0.2 本批不做（强制）

- **不做**：端点级负载均衡 / 失败自动切换。　**理由**：静默换端点会让「这次为什么用这个模型/这家价格」不可复现，与 `generation_log` 的可追溯性冲突；且切换后产出风格会变。　**留给**：明确不做，改为人工在设置页改配置。
- **不做**：按提示词 ID 单独指定端点（`prompt_models`）。　**理由**：五档已覆盖「规划/正文/润色/审校/长通读」的分工，用户诉求是按角色分，不是按提示词分。　**留给**：出现单条提示词需要独立端点的实际案例时。
- **不做**：把密钥写进 `books/<书名>/config.json`。　**理由**：书目录是创作档案、会导出与备份，密钥进去等于随档案扩散。　**留给**：明确不做。
- **不做**：迁移既有书的 `model_stages` 值。　**理由**：无前缀值自动落到默认接口，行为与现在完全一致，不需要动数据。
- **不做**：端点健康检查 / 连通性看板。　**理由**：设置页已有「测试连接」，多端点后改为按接口分别测；完整看板无决策价值。　**留给**：明确不做。

## 2. 契约与数据格式

### 2.1 `settings.json` — `providers` 从"固定一个"变"任意多个"

```jsonc
// 改前
{ "providers": { "openai": { "api_key": "...", "base_url": "https://a/v1" } } }

// 改后（结构不变，只是允许更多键；openai 保留为默认端点）
{
  "providers": {
    "openai": { "api_key": "...", "base_url": "https://a/v1", "label": "主中转站" },
    "backup": { "api_key": "...", "base_url": "https://b/v1", "label": "备用站" }
  }
}
```

- 键名（端点名）限 `^[a-z][a-z0-9_-]{0,23}$`，大小写不敏感一律转小写。
- `label` 可选，仅用于 UI 显示；缺省显示端点名。
- 默认端点固定为 `openai`：`llm.client()` 无参时用它；旧数据无需迁移。

### 2.2 模型值语法

| 写法 | 含义 |
|---|---|
| `gemini-3.8-flash-high` | 默认端点（`openai`）+ 该模型 |
| `backup@gemini-3.8-flash-high` | 端点 `backup` + 该模型 |

- **分隔符是 `@` 而不是 `:`**。实测中转站的模型清单里存在 `gemma4:31b`、`nemotron-3-nano:30b`
  这类自带冒号的模型名，用冒号会把它们误判成端点前缀。`@` 在模型名里罕见，无歧义。
- 判定规则：`@` 前那一段**是已配置的端点名**才算前缀；否则整个字符串就是默认端点的模型名
  （因此 `gemma4:31b` 不受影响）。代价是"端点名拼错"会被当成模型名发出去，由端点返回
  `model_not_found`——这条错误现已能明确显示（见规格12 §1.1 的 `error_brief`）。
- 价格表的键同样用 `端点@模型`。

### 2.3 `models.ModelRef` 扩展

```python
@dataclass(frozen=True)
class ModelRef:
    model: str      # 发给端点的裸模型名
    source: str     # book | global_stage | fallback | default
    provider: str = "openai"   # 端点名
    raw: str = ""   # 原始配置值（含前缀），供价格查找与诊断
```

`resolve()` 的层序不变（规格12 §2.3），只多解析出 `provider`。

### 2.4 SQLite

`generation_log.provider` 列已存在（规格12），本规格只改写入值：由常量 `"openai"` 改为真实端点名。历史行保持 `openai`/`NULL`，不做回填。

### 2.5 状态机 / 提示词

无变更。

## 3. 接口

| 端点 | 方法 | 入参变化 | 返回值变化 | 错误码 |
|---|---|---|---|---|
| `/api/models` | GET | 新增可选 `?provider=名字`；省略 = 默认端点 | 新增 `provider` 回显 | 端点不存在 → 404；端点不可达 → 200 + `ok:false` |
| `/api/settings/test` | POST | 新增可选 `provider` | 回显 `provider` | 端点不存在 → 404 |
| `/api/settings` | GET/PUT | `providers` 允许多键 | 每个端点分别掩码 + `has_key` | 端点名非法 / 缺 `base_url` → 422 |

## 4. 迁移与兼容（强制）

- **老数据**：单端点 `providers.openai` 原样有效；`model_stages` 无前缀值 = 默认端点，行为不变。**零迁移**。
- **幂等**：本规格不引入自动改写数据的迁移，重复执行无副作用。
- **删库 rebuild**：不受影响（端点配置在 settings，书目录零改动）。
- **降级路径**：旧代码读到 `backup@xxx` 会把整串当模型名发出去 → 端点返回 404。**这是已知的不可逆降级**：回滚代码前须先把带前缀的值改回裸名。写入此条以避免"回滚了却不知道为什么全挂"。
- **回滚**：代码回退 + 把 `model_stages` 的前缀去掉（默认端点不受影响）。

## 5. 失败模式（强制，fail-closed）

| 可能的静默失效路径 | 对策 |
|---|---|
| 端点名拼错 → 被当成模型名发出去 | 端点返回 `model_not_found`，报错已能明确显示（规格12 §1.1）；UI 选择器只能从已有端点里选，不提供手填端点 |
| 模型名自带冒号被当成端点前缀 | 分隔符用 `@`；`@` 前必须是已配置端点名才生效 |
| 某端点 key 为空 → 请求 401，用户以为是主站挂了 | `resolve` 不校验 key（属运行时）；`llm.client(p)` 缺 key 时抛 `LLMError("端点 X 未配置密钥")`，错误摘要点名端点 |
| 价格表只有裸模型名 → 两个端点同名模型串价 | 查找顺序：`端点:模型` → 裸模型名 → 0 + 告警 |
| `/api/models?provider=` 传了不存在的端点 | 404，不静默回落到默认端点 |
| 前端把带前缀的值当模型名发给 `/api/models` | 选择器分别维护「接口」和「模型」两个下拉，请求时只传接口名 |
| 密钥被写进书目录 | 本规格不提供该入口；`config.json` 的 `model_stages` 只存 `端点:模型` 字符串 |
| 回滚后带前缀值被当模型名 | §4 已列为已知降级，实施报告须写明回滚步骤 |

## 2. 契约与数据格式

### 2.1 不变项

- 书级 `style/语料.txt`、`style/特征卡.md`、`style/范例.json`、config开关格式无变更。范例仍按规格06最多两段、合计1200可见字符，整段舍弃与stale规则不变。
- SQLite表、章节状态、frontmatter、提示词ID/变量/version无变更；W1文件保持批准时内容。
- `style/候选范例/sources.json`只是本地候选来源记录，**不自动作为正式范例索引或启用授权**。运行时不扫描全局候选库；正式选用仍走现有人工保存流程。
- deslop现有score、hits、ineffective、word_count、hits_count、density_penalty和D-14保护区规则不变。

### 2.2 新增结果字段

`DeslopResult.to_dict()`追加可兼容的 `metrics`，版本1；旧结果可以没有该字段。

- `metrics.version=1`。
- `metrics.paragraphs`：count、mean_chars、median_chars、p90_chars、short_ratio。长度是去空白可见字符数；short_ratio仅统计不超过10个可见字符的段落占比，不是违规阈值。空文count=0，其余统计null。
- `metrics.simile_cues`：status、scope、count、per_1000_chars。scope明确为 `all_text`，分子与分母均来自全文含对白；不是“叙述部分密度”或语义比喻数。空文密度null。
- 可用时status=`measured`；配置缺失/非法等无法计量时status=`unavailable`、计数/密度null并给出原因，不能伪装为0或改善。
- 可返回有界线索位置供回读，不混入DeslopHit或原有惩罚。

段落按空行解析，CRLF/LF/CR与空白行同口径，保留段内换行；不能把每个物理行机械当一段。P90使用排序后最近秩 `ceil(0.9*n)`；展示数值统一有限小数，测试锁定口径。

显式线索来自新增lint种子文本，不在Python硬编码词表。最长匹配优先、重叠只计一次；排除图像/头像/像素等词面误匹配。词面扫描不能证明暗喻或修辞质量。新计量与原D-14保护扫描独立，**不移除保护、不改变旧分**。新计量配置不可用不影响旧检查结论。

词表为 `lint/simile_cues.txt`、`lint/simile_exclusions.txt`，每行一个1—64个无空白可见字符的字面词条，空行与`#`开头注释忽略；最长匹配优先、重复去重。词表缺失、空表、非法字符或解码失败只使线索计量不可用。返回位置至多20条，`start/end`为输入原文的Python字符偏移、`line`按原始换行计算，计数不受位置上限影响。均长/中位数/密度保留两位小数，短段占比保留四位小数。

## 3. 接口与展示

| 端点 | 变化 |
|---|---|
| `GET /api/books/{book}/chapters/{no}/deslop` | 入参、状态码不变；返回追加metrics |
| 现有style接口、generation/review/fix/polish | 无契约变更；不向模型增加计量反馈 |

`web/src/api/types.ts`将metrics定义为可选，工作台原机检区域显示“段落平均长度”“显式比喻线索密度”，并附段数、分布/短段占比及统计口径。旧后端/历史结果未提供时显示“未提供”，无法计量显示原因，不能展示为0或绿色通过。不新增页面、写入口、章检请求或自动改稿按钮。

## 4. 迁移与兼容（强制）

- 不迁移旧书、旧卡、旧正文、历史日志或旧检查JSON；重复查看不写档。
- 老结果缺metrics仍正常显示；新字段被旧客户端忽略。
- source_path仅用于来源记录，不由服务端按客户端任意路径读文件；离线回归不依赖桌面原库存在，不读真实books/data。
- 回退代码只忽略metrics与候选资产；不能因此删除书级素材或自动还原正文。
- 六组候选的原段文字和指纹保持可追溯；未来用户编辑应更新候选记录，不沿用旧指纹。

## 5. 失败模式（强制）

| 失效路径 | 对策 |
|---|---|
| 只放文件就宣称范例生效 | 离线回归检查实际system/user、所选ID、全文和指纹；缺正式卡/关闭开关仍不注入 |
| 范例碎成孤立段或预算截半句 | 使用来源记录中的完整多段范围，通过现有save_examples，沿用整段预算 |
| 全部按UTF-8读取旧参考书 | 候选已规范UTF-8；来源编码保留，不让运行时读取外部整库 |
| 平均值掩盖碎段分布 | 同时给出段数、中位/P90与短段占比，不单凭均值判优劣 |
| 保护区把全文计量清零 | 新metrics独立、明确all_text；保留D-14旧契约 |
| 词面线索被解释成真人概率 | UI明确“显式比喻线索”，不提供AI概率或文学合格分 |
| 配置坏/缺失但显示0 | unavailable/null/原因；旧检查继续，不新增门禁 |
| A/B卡和开关也改变 | C冻结卡、开关、细纲、模型、其他参数，只有范例不同 |

## 0. 前端技术栈定案（2026-10-26）

初版按"免构建 vanilla JS/CSS"交付；本节为用户定案的重写目标，**已于 2026-10-26 实施完成**（Vue3 版替换 vanilla 版）。§1–§4 的页面清单与验收要求不变。

**技术栈**：

| 层 | 选型 | 说明 |
|----|------|------|
| 框架 | Vue 3（组合式 API，`<script setup lang="ts">`） | TypeScript strict |
| 路由 | vue-router 4 | §1 页面清单即路由表 |
| 状态 | pinia | store 只作会话缓存，数据真相源仍是后端 |
| 组件库 | element-plus | 按需自动导入（unplugin-vue-components + unplugin-auto-import） |
| 构建 | vite | `web/` 为项目根，产物输出 `web/dist/` |
| 样式 | sass + tailwindcss | 分工：布局/原子样式用 Tailwind；EP 主题定制用 SCSS 覆盖 EP 的 CSS 变量 |
| HTTP | axios | 统一拦截器封装；SSE 流式生成走原生 fetch/EventSource（axios 不支持流式） |
| 工具 | @vueuse/core | 组合式工具库（推荐） |
| 质量 | eslint 10（flat config，create-vue 形态）+ prettier 3 + husky/lint-staged 预提交钩子 + .editorconfig | 已配置（2026-10-26） |

**补充定案**：

- **Tailwind 与 element-plus 共存**：关闭 Tailwind preflight（或限制作用域），保证 EP 组件默认外观不被 reset 破坏；冲突以 EP 外观为准。
- **Node ≥ 20**；`.gitignore` 挡 `node_modules/`（`web/dist/` 已被现有 `dist/` 规则覆盖）。
- **提交规范**：pre-commit 钩子对暂存的前端文件跑 `eslint --fix` + `prettier --write`（lint-staged，钩子内 cd 到 web/ 执行）；Python / Markdown 不受钩子影响。
- **服务方式**：`ainovel/api.py` 的静态挂载从 `web/` 改为 `web/dist/`；开发时 `python run.py`（后端 8765）+ `npm run dev`（Vite dev server 把 `/api` 代理到 8765）并行。
- **打包**：PyInstaller 分发对象由 `web/` 改为 `web/dist`（README 打包流程同步）。
- **不变项（红线）**：后端 API 契约（全部 `/api/*` 路由）、§1 页面清单与功能、两个人工确认关、"信息密度优先、不做视觉设计"的 UI 原则。

## 1. 页面清单

| 页面 | 里程碑 | 功能 |
|------|--------|------|
| 书架 | M1 | 书列表/新建（向导：书名→题材→字数→模型）/删除（二次确认，提示将删文件） |
| 书总览 | M1 | 档案导航（Bible/角色/地点/伏笔/大纲）、章节列表（状态机徽标）、成本汇总、卷末审计入口 |
| 档案编辑 | M1 | 左树右编辑器；结构化字段（力量体系表、角色动态状态）用表单，长文本用 Markdown；AI 生成按钮 → diff 预览 → 采纳 |
| 章节工作台 | M2 | 见 §2（核心页） |
| 裁决队列 | M2 | 台账冲突列表 → 采纳AI / 保留档案 / 手改，处理后归零 |
| 设置 | M0 | API keys（掩码）、模型映射（含 base URL）、连通性测试、lint 词库编辑、阈值调整 |
| 导出 | M3 | 章节合并导出 txt/md、全书打包 zip |

**非目标**：移动端、多人协作、自动发布（手动复制粘贴）、云端同步、账号系统。

## 2. 章节工作台（核心页）

- 顶部：章号 / 状态机徽标 / 当前版本号 / 本章累计成本
- **细纲区**：frontmatter 表单化（钩子类型下拉、伏笔操作行内编辑）+ 场景清单 Markdown；【确认细纲】按钮
- **生成区**：流式正文预览；【开始生成】
- **机械检查报告**：命中列表（级别/规则ID/行号/词），点击跳转正文位置
- **审校报告**：五维分数条 + 问题列表（类别/severity/原文引用/建议）；【修复】【豁免（必填理由）】
- **定稿**：二次确认 → 快照；版本列表可回看任意快照，【从此版本重写】
- **装配预览（折叠面板）**：13 槽位实际注入内容 + 各槽 token 估算——排查生成跑偏的第一入口，必须有
- 卷首三章自动显示"黄金三章专项"标记

## 3. M4 验收清单（v1 完成线，逐条打勾）

1. 建书 → G1-G5 四条生成链跑通并人工改定入库
2. 第一卷 ≥10 章 × 2500 字连续闭环，中断恢复至少实测 1 次
3. 最终定稿版本机械检查全绿（阻断 0 命中）
4. rubric 均分 ≥85，无未豁免的 blocking
5. 单章成本 ≤1 元（超出的章节有归因分析）
6. 台账零硬冲突：卷末审计 V6 通过，裁决队列清零
7. 3 个回归案例留存（第 1/5/10 章各一：细纲 + 装配快照 + prompt digest），可一键重跑对比
8. 本人通读门：每章读一遍，"愿意发"才定稿——这条没有自动化替代
9. 导出 txt 合并版完整无乱码

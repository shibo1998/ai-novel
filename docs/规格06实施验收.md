# 规格06实施与离线验收

## 交付范围

基线为 `253c62e`，按已批准的 `docs/specs/06-生成文风与安全去AI味规格.md` 实施。

- 提示词仅渲染正文，保留原有ID、模型档位和温度，相关内容修改递增version；移除机械文体配额及强制凑问题复审。
- 实际system/user与运行元数据分离，上下文和合同去重，预算覆盖完整实际输入，请求快照与组合摘要可回看。
- 文风开关对生成、专项、长度调整、审校和润色一致生效；范例稳定选择完整段落，指纹变化时不使用旧范围。
- F1只返回未保存草案，正式文风卡和启用由人工操作；两处前端入口复用同一编辑会话。
- M-12/D系列仅为建议，历史标签仍可追溯；敏感词和其他硬门禁保持。
- V2只提出精确范围补丁，程序构造候选；V3同时比较原稿和候选，并分别核对六维保真与读感。
- 润色候选文件持久化于书级revisions目录，不进入正文索引/导出/记忆；只有人工采纳接口写正式稿。
- 采纳核验源稿完整文件、双指纹、版本、修订、主状态与依赖，异常可回滚或按applying标记幂等恢复；外部第三种正文不被覆盖。

## 有意行为变化与兼容

`POST /polish` 现在只表示生成预览，`ok`表示请求处理结果；是否可采纳应检查 `ready/status/checks`，是否已写回检查 `applied`。旧无请求体调用也不会保留自动写回入口。旧书级V2/V3不符合interface_version=2时，在模型调用前返回升级要求。

没有卡片时，即使配置开关为true，也不构造有效文风上下文；关闭开关不读取书级文风资料。已有书稿、人工卡、语料和书级提示词覆盖不批量迁移。

旧规格01—05和README已增加覆盖引用。没有新增Python或前端运行依赖，没有新模型供应商或采样参数。

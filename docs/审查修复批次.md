# 审查修复批次（2026-10-27）

## 目标与边界

本批修复审查确认的数据损失、检查假绿、路径穿越和前后端入口缺失，不新增运行时依赖，不触碰真实 books/data，不替代细纲确认、定稿和敏感词人工处理。

## 已实现与验收依据

- 上传：书名校验、落盘路径 containment、严格 base64、32MB 上限。
- 正文：书级进程内重入互斥，旧页面 `expected_revision` 比对，修复/润色/手改后旧机检立即失效。
- 审校与定稿：V1 五维 0–100 有限数字与完整问题举证校验；审校/定稿要求当前正文指纹的有效机检或定稿前明确人工豁免。未生效规则不可豁免。
- 润色：完整 `check_full`、原文敏感词禁止自动改写、字数 ±10%、保真长度比例、句末数量和 4-gram 覆盖检查，V3 必须明确 pass，否则保留原文。
- 记忆卡：先抽取校验候选；应用失败回滚角色/台账/记忆卡/摘要/状态索引/FTS，保留模型调用费用日志。失败定稿仍是 finalized，可从缺卡入口补做；历史章不得覆写角色卡后续状态。
- 状态卡：V4 只写 `STATE.proposed.md`，采纳前验证来源和两端指纹；人工采纳后写 `STATE.md` 与已确认状态副本。装配不直接消费未确认状态快照。前端有差异查看、采纳、丢弃。
- 时间线：作者真相和读者释放两表可在状态页维护；写前验证重复编号、角色、章号、引用与过期编辑，非法保存不覆盖原文件。
- 外挂/导入：保留实际章号、禁止覆盖已有档案、持久化断点；摘除不级联删除运行历史；重建覆盖内置/外挂目录，清孤儿章节，记忆卡恢复结构化状态。

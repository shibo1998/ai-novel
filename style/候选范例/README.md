# 文风候选范例

> 六组、每组两个完整片段，来自用户授权的本地参考文本。它们是**待作者确认的候选**，不是全局默认风格，也未写入、启用任何真实书。

## 选用原则

- 同一本书先选一组，不把多个题材或作者混成一份范文。
- 原文只参考表达节奏、观察顺序和场景推进，不能带入原文角色、剧情、能力等级或专有设定。
- 每组两个片段合计不超过现有装配的1200可见字符预算；片段范围见 `sources.json`，不是把文件所有段落拆成孤立范例。
- 已通读的TXT非空物理行在这些范围内是完整段落，统一为空行分段、UTF-8/LF；段内措辞不改。原文疑似错字亦保留，不冒充原著校订。
- 本目录是人工素材资产，运行时当前**不会自动扫描或注入**。正式使用仍需按规格06保存书级语料、确认范例范围与特征卡，并显式启用。

## 特征卡草案（不是正式卡）

以下只来自所列小样，不代表对整本书的全面分析。作者认可后可编辑保存为书级正式卡，不直接照搬为配额。

### restrained · 克制修仙

观察：人物先看地形和他人反应，再改变动作；体力与伤处造成后果；害怕、灰心、感激可直接写，不必每次变成身体套式。

适用：探索、逃生、劳动、修炼成本与审慎选择。参考证据：候选段3、5、8–11。

例外：不要求所有动作都缓慢，不复制七玄门、舞岩或韩立的经历。片段里有重复称谓与叙述解释，不把它们提炼成“每段必须重复”。

### clear_action · 清晰动作

观察：动作对象、发力方向、命中效果连贯；练习有不成功的反馈；装备数据是解释动作条件，不是倒计时节拍器。

适用：训练、检修、操作、战斗技术过程。参考证据：候选段1–3、9、16–21。

例外：小样本身有短段、数字和明喻，只取动作可理解性，不照搬单句断行、反复报数字或枪法设定。

### suspense · 悬疑推理

观察：环境不合理处先被人物发现；疑问由可见细节触发；人物用不同的职业关注点追问并反驳，而非旁白一次解释全部。

适用：调查、交涉、辨认规则与信息差。参考证据：候选段3–11、12、15–21。

例外：悬疑本来会使用短段，不能据此把所有场景写成碎段。这里只参考对白组织，不把原文时间推理当本书事实或推理答案。

### urban · 都市对白

观察：人物之间有追问、吐槽、迟疑；廉价购物袋、花生油、擦汗等生活物件使场景具体；小动作服务于跨马路的当下任务。

适用：日常相遇、轻松对白、人物初次亮相。参考证据：候选段1–10、11–23。

例外：不把所有人物写成吐槽役，不复制黑缎缠目和原文人设；小样有短段与修辞，不能当全书段长基线。

### historical · 历史文白

观察：术语通过提问、尝试与纠正出现；解释被人物打断，回到当前问题；“过所”等知识改变对身份的判断。

适用：考据型交涉、识别时空、身份与制度约束。参考证据：候选段7–16、17–24。

例外：不凭两个片段概括全书古文比例，不把专业术语填进非历史题材，也不把旁白考据当本书已确认世界观。

### light_daily · 日常与岁月

观察：相熟人物的称呼和琐事表现关系；同一段生活从玩笑过渡到送别；他人的变老、孩子出生使时间流逝可见。

适用：休整、熟人生活、分别、时间跨度过渡。参考证据：候选段1–16、17–30。

例外：不要求每章抒情或插笑料，不用“长生者必须送别”替代本书情节。原文个别概括和升华只作样本观察，不新增到W1规则。

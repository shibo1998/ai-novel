阅读本章正文，抽取本章记忆卡，供后续章节使用。只记录客观变化，不做评价；与档案冲突处由程序送人工裁决。

【正文】
〖正文〗

【章号】〖章号〗
【现有角色名清单（char_updates 的 name 必须与清单一致或正文新出场；新角色才进 new_chars）】
〖现有角色名清单〗
【活跃伏笔编号清单（foreshadow_ops 的 fo_id 只能引用其中编号，或以 plant 新增）】
〖活跃伏笔编号清单〗

【抽取内容（T9-C 固定字段）】
- 已有角色的状态变化：境界/位置/伤势/情绪/关系/持有物/生死；角色本章新获知的关键信息（known_info，防提前知情穿帮）
- 新出场角色：姓名/身份/一句话特征/立场
- 新出现地点与场景
- 伏笔动作：新埋设（编号/内容/预计回收方向）；本章推进/回收的伏笔编号
- 需人工补录的世界观/体系规则（new_settings_pending）
- 本章关键事件一句话摘要（event_summary）；时间流逝（time_elapsed，"半日/一夜/三天"式）
- **结构化状态增量（state_delta）**：只写本章**发生变化**的角色，每人一条；
  power_level 必须原样使用圣经力量体系里的境界名（不得自创）；arc_stage 用 0-5 整数；
  knowledge 只写本章新获知的事实（防"提前知情穿帮"）；没变化的角色不要列
- **时间线候选（timeline_candidates）**：本章出现、可能属于"故事真相"的事件（仅候选，交人工确认，不直接入库）

【输出】只输出一个 JSON 对象，无其他文字：
{
  "chapter_no": 〖章号〗,
  "char_updates": [{"name": "", "changes": {"realm": "", "location": "", "injuries": [], "inventory": [], "emotion": "", "alive": true, "known_info": [""]}}],
  "new_chars": [{"name": "", "identity": "", "stance": ""}],
  "new_locations": [""],
  "foreshadow_ops": [{"op": "plant|advance|pay", "fo_id": "", "note": ""}],
  "new_settings_pending": [""],
  "state_delta": [
    {"character": "", "location": "", "physical": "", "mental": "",
     "power_level": "", "arc_stage": 0, "knowledge": [""], "goals": [""]}
  ],
  "timeline_candidates": [{"event": "", "characters": [""], "reader_known": false}],
  "event_summary": "",
  "time_elapsed": ""
}
每条字段控制在 40 字以内（state_delta 过长会导致 JSON 截断失败）。
